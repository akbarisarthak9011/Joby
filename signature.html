Aperçu Visuel de la Signature
💡 Comment l'insérer dans votre messagerie :
  1. Cliquez sur le bouton bleu « Copier la signature (Format enrichi) ».
  2. Dans Outlook : allez dans Paramètres ⚙️ > Courrier > Composer et répondre > Signature électronique.
  3. Dans Gmail : allez dans Paramètres ⚙️ > Voir tous les paramètres > Général > Signature.
  4. Faites simplement Ctrl + V (ou Cmd + V sur Mac) dans le champ de signature, puis enregistrez !
